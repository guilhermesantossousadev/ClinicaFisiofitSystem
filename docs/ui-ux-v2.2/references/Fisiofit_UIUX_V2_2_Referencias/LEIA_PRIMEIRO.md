# FISIOFIT — REFERÊNCIAS VISUAIS PARA UI/UX V2.2

## Comece aqui

1. Abra `GALERIA_REFERENCIAS.html` no Safari conectado à internet. Ela mostra 16 capturas de referência com links e comentários, e as propostas originais locais.
2. Abra `MOSAICO_DE_REFERENCIAS.png` para ver todos os estudos visuais autorais sem internet.
3. Envie este ZIP junto com o Prompt Mestre V2.2 ao Codex.
4. Copie também o texto em `02_GUIAS_E_FONTES/ADENDO_PARA_O_PROMPT_V2_2.md` como instrução suplementar, se necessário.

## Conteúdo

- `01_VISUAIS_OFFLINE/`: 10 estudos visuais originais desenhados para mostrar as adaptações desejadas à Fisiofit; não são capturas do Jane ou de nenhum outro aplicativo.
- `GALERIA_REFERENCIAS.html`: coleção navegável de 16 screenshots de produtos pesquisados. As fotos dos produtos estão **vinculadas por URLs de origem** e aparecem com internet. Não estão fisicamente embutidas no ZIP porque o download não esteve disponível.
- `manifesto_referencias.json`: origem, URL da imagem, objetivo, adaptação e restrições por referência.
- `02_GUIAS_E_FONTES/REFERENCIAS_COM_FONTES.md`: links diretos e matriz de aplicação.
- `02_GUIAS_E_FONTES/ADENDO_PARA_O_PROMPT_V2_2.md`: orientações para aproveitar este pacote no trabalho já definido.

## Hierarquia visual

1. **Jane:** referência principal de calendário temporal, múltiplos profissionais, controles de navegação e seleção.
2. **Fresha / Cliniko:** calendário e agenda de profissionais.
3. **Zenamu / Mindbody:** turmas e sessões recorrentes.
4. **Linear:** filtros, navegação e manutenção de contexto.
5. **Notion:** abertura de detalhes sem abandonar a tela.
6. **Shopify Polaris:** tabelas, formulários, consistência.
7. **Stripe:** clareza da leitura financeira.

**Direito de uso:** as capturas de terceiros são usadas apenas como links de estudo de referência. Não copiar logotipos, interfaces pixel a pixel, assets, identidades visuais, textos ou código. O produto final deve ser original e respeitar dados de pacientes. Todas as imagens offline são estudos novos, ilustrativos, sem dados reais.
